# Homepage hero — Crossing the kelir

## Asset ID
`HRO-001` · owner: product/brand lead · priority P0.

## Objective
Show that Hanoman carries documented intent into visible, reviewable work and returns evidence.

## Product truth
Hanoman orchestrates docs-driven agent sessions in isolated worktrees; humans monitor and decide from the dashboard.

## Character tier
Narrative · `MOD-001` · `GST-03` moving toward `GST-10`, `EXP-03`, `TAL-02`.

## Composition
Wide 16:9 kelir field. Anoman crosses left to center with intent folios; a Buntut path enters a visible
session lane and returns as evidence toward a calm control-room proof area. Figure 40–50%; reserve the
right third for copy. Human control appears as a grounded hand/cursor cue, never a second hero.

## Layer map
`bg / environment-kelir / intent-folios / character-base / character-gesture / session-path / buntut-fx / evidence / foreground / text-safe`.

## Responsive outputs
16:9 desktop, 4:3 tablet, 9:16 mobile, plus 1:1 and 4:5 social crops. Redraw the path so eye, mandate,
session, evidence, and human-control cue survive; do not blind-center-crop.

## Alt-text intent
“Anoman carries documented intent through a visible agent-session path and returns evidence to a human-controlled dashboard.”

## Human handoff
Provide three thumbnails: crossing dominant, return-path dominant, balanced. After Gate 3, redraw the
canonical profile and hands, build editable depth layers, then test every crop before Gate 4.

## AI prompt
`IDENTITY_CORE + TIER_NARRATIVE + STYLE_EDITORIAL_WAYANG + COMP_HERO + MOTIF_DUTA`; emphasize
kelir passage, folios, abstract session lane, evidence return, calm human control. Apply `NEGATIVE_CORE`.

## Do
Keep one circular journey—intent outward, evidence back—and make reviewability clearer than spectacle.

## Don't
Don't bake copy/logo, invent fake UI, show autonomous approval, add a second heroic character, or mirror the profile.

## Acceptance
- Gate 0–1: product mapping, reference rights, and copy-safe requirement approved.
- Gate 2–3: canonical silhouette passes; one selected thumbnail communicates intent → work → evidence.
- Gate 4: anatomy, crop, contrast, and alt-text reviews pass at 320 px preview.
- Gate 5: editable layers, 3200 px raster minimum, responsive exports, provenance, and manifest pass.
