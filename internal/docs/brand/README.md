# Hanoman brand book

> **Kekuatan yang mengemban amanat.**  
> **Power in service of intent.**

Hanoman adalah control room open-source bagi tim engineering kecil yang menjalankan coding agent
lintas project. Brand ini mengikat daya agent pada konteks, visibilitas, kendali tim, dan pengetahuan
yang bertahan setelah session selesai.

Hanoman is the open-source control room for small engineering teams running coding agents across
projects. The brand binds agentic power to context, visibility, team control, and knowledge that
outlives the session.

## How to use this book / Cara memakai brand book

- Untuk keputusan arah produk, mulai dari [Foundation](01-foundation.md) dan
  [Four lakons](02-four-lakons.md). / For product-direction decisions, start with Foundation and Four
  lakons.
- Untuk menulis copy, baca [Personality & voice](03-personality-voice.md), lalu pilih pola dari
  [Messaging](04-messaging.md) atau [Brand in practice](06-brand-in-practice.md). / For copy, read
  Personality & voice, then choose a pattern from Messaging or Brand in practice.
- Untuk desain komunikasi, gunakan [Visual identity](05-visual-identity.md). Untuk token dan komponen
  UI, [design system](../design-system/design-system.md) tetap menjadi Source of Truth. / For
  communication design, use Visual identity. The design system remains the Source of Truth for UI
  tokens and components.
- Untuk memesan atau menghasilkan aset, mulai dari [Illustration system](illustration/README.md) dan
  pilih brief berdasarkan asset ID. / To commission or generate assets, start with the Illustration
  system and select the brief by asset ID.
- Untuk klaim budaya, istilah, atau pengembangan simbol baru, periksa
  [Sources & cultural notes](sources.md) lebih dulu. / For cultural claims, terminology, or new
  symbolic work, consult Sources & cultural notes first.

## Authority / Kewenangan

Brand book menetapkan makna, suara, pesan, dan prinsip ekspresi Hanoman. Ia tidak mengubah kontrak
produk di `internal/docs/**`, tidak menggantikan design system, dan tidak menjadi lisensi untuk
mengorbankan keterpahaman demi metafora.

This book governs Hanoman's meaning, voice, messaging, and expressive principles. It does not alter
the product contracts in `internal/docs/**`, replace the design system, or license metaphor at the
expense of clarity.
