# Product-state illustration family

## Asset ID
`PST-001`–`PST-006` · six dashboard-support masters.

## Objective
Help users identify a literal UI state and next action before adding light character warmth.

## Product truth
UI copy owns cause, status, and recovery. Illustration never diagnoses, promises success, or substitutes mythic language for actionable information.

## Character tier
Mascot · `MSC-001`; low mythic intensity, clear profile gesture, product state more prominent than lore.

## Locked anchors
Retain the approved compact proportion, one-eye profile, supit urang, ulur-ulur, dignified posture, and one readable tail.

## Composition
Calm 4:3 empty-state field, centered state cue, one mascot gesture, ample copy region, no imitation UI controls.

| ID | Scene and tone | Literal no-metaphor fallback | Copy relationship | Alt text |
|---|---|---|---|---|
| `PST-001` | Welcome pose opens a bounded path; encouraging | Simple path + start marker | Copy explains first setup action | Anoman welcomes the user to start setup |
| `PST-002` | Observe pose beside an empty tray; neutral | Empty tray/backlog outline | Copy explains how to add work | Anoman observes an empty backlog |
| `PST-003` | Work pose beside a moving session marker; focused | Active state dot/path | Copy names session and monitoring action | Anoman watches an active session |
| `PST-004` | Ask pose at a decision fork; patient | Fork + human decision marker | Copy states the exact decision needed | Anoman waits for a human decision |
| `PST-005` | Restrained celebrate pose at a completed marker; relieved | Check/result marker | Copy names what completed and next review | Anoman acknowledges a completed result |
| `PST-006` | Concerned but calm pose beside a reconnect path; reassuring | Error marker + recovery arrow | Copy must state cause and recovery | Anoman points to a recoverable error path |

## Layer map
`bg / state-cue / character-base / character-gesture / buntut-fx / foreground / text-safe`; keep copy and UI outside the master.

## Responsive outputs
4:3 and 1:1; 160, 320, and 480 px; mandatory one-color silhouette and minimum 160 px state-recognition test.

## Alt-text intent
Use row text only when the illustration adds information beyond adjacent status copy; otherwise mark decorative.

## Human handoff
Design literal fallback first, add mascot second. Use `IDENTITY_CORE + TIER_MASCOT + COMP_PRODUCT + row state + NEGATIVE_CORE`; manually correct all canonical cues.

## Do
Let copy carry precise state and next action; keep error recoverable and emotionally calm.

## Don't
Don't use lore instead of a cause/recovery, imply automatic success, fake controls, or make empty states shameful.

## Acceptance
Gate 0 validates state/copy owner; Gates 1–2 validate mascot; Gate 3 selects literal-first compositions;
Gate 4 passes one-color/minimum-size/access checks; Gate 5 includes six editable assets and alt/decorative decisions.
