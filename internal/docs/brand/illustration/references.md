# References / Rujukan

## Source hierarchy / Hierarki

1. Academic, museum, cultural institution
2. Documented collection, dalang, or craft source
3. Secondary editorial source
4. Visual inspiration only—tidak mendukung cultural claim

## Surakarta sources

- Khoiron Mahfudzi, [perbandingan Anoman Surakarta–Yogyakarta](https://repository.um.ac.id/12589/):
  mendukung starting observations tentang mata, kepala, bahu, supit urang, dan ulur-ulur.
- Agus Ahmadi, [kriya wayang purwa Surakarta](https://repository.isi-ska.ac.id/id/eprint/2977/1/Ag.%20Ahmadi.pdf):
  mendukung klasifikasi Anoman sebagai rewanda dan peran bentuk/busana.
- Bambang Suwarno dkk., [kajian wanda Surakarta](https://jurnal.isi-ska.ac.id/index.php/gelar/article/view/1487):
  mengingatkan bahwa rupa, wanda, fungsi pertunjukan, dan sanggit saling terkait.
- ISI Yogyakarta, [ikonografi dan teknik pakeliran Surakarta](https://digilib.isi.ac.id/161/):
  rujukan lanjutan ikonografi/teknik, bukan izin menyalin gambar.

## Reference record template

| Field | Isi |
|---|---|
| ID | `REF-###` |
| Title / creator | Judul dan pencipta/perajin |
| Institution | Museum, kampus, koleksi, atau penerbit |
| Tradition/style | mis. wayang kulit purwa Surakarta |
| Date / URL / accessed | Tanggal objek, link, tanggal akses |
| Supported claim | Satu klaim yang boleh ditopang |
| License/status | Public domain, licensed, permission, view-only |
| Allowed use | Research, image reference, reproduction, AI reference |
| Reviewer note | Perbedaan, risiko, dan keputusan |

## Reference board acceptance

Gate 1 butuh minimal: satu sumber silhouette/classification, satu comparative form, satu
wanda/function, satu approved visual object, rights tercatat, dan cultural reviewer menyetujui.

## Boundaries

Jangan menyalin museum/book scans, mencampur pakem regional, memakai gambar tanpa izin dalam AI
reference pack, meminta “in the style of” seniman hidup, atau menganggap satu objek sebagai bentuk
kanonik tunggal.
