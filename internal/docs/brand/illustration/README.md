# Hanoman illustration system

Brief produksi untuk membuat ilustrasi Hanoman melalui illustrator manusia atau AI-assisted workflow;
bukan kumpulan artwork final. / Production briefs for human illustrators and AI-assisted workflows;
not finished artwork.

## Quick facts / Ringkasan

- 3 tier: **Narrative, Editorial, Mascot**
- 41 deliverable, hybrid production, static-first dan layer-ready
- Gate 0 product truth, lalu Gate 1–5: cultural, character, composition, craft, delivery
- Jangkar: wayang kulit purwa gaya Surakarta; gaya: editorial wayang kontemporer

## Authority / Kewenangan

`product docs → brand foundation/lakons → visual identity → illustration system → asset brief → delivery manifest`

Lapisan yang lebih hilir tidak boleh mengubah fakta atau karakter di atasnya. / A downstream layer
may not override upstream product truth or character rules.

## Start gate / Gerbang mulai

Jangan produksi sebelum owner, product truth, audience/action, surface, tier, asset ID, reference
board, executor path, rights, dan reviewer tercatat. Copy [master template](05-production-brief-template.md).
